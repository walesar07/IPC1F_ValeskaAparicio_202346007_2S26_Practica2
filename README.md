# Práctica 2: Quetzal Space Defender - Side Scroller

**Curso:** Introducción a la Programación y Computación 1
**Universidad de San Carlos de Guatemala — Facultad de Ingeniería**

**Nombre:** Valeska Aparicio
**Carnet:** 202346007

## Descripción

Simulador de combate espacial desarrollado en Java con interfaz gráfica
(Swing), en el que el jugador atraviesa un cinturón de asteroides y naves
enemigas moviéndose de izquierda a derecha. Aplica conceptos de
Programación Orientada a Objetos e hilos: cada enemigo, asteroide, premio
y proyectil en pantalla es manejado por su propio hilo independiente.
